# SpyScan

SpyScan is an Android security awareness application developed using Kotlin and Android Studio. The project helps users better understand application behavior, selected privacy permissions, and security-related indicators on Android devices.

## Features
- App usage analysis
- Permission-based risk scoring
- Accessibility and overlay checks
- Sideload detection
- Root checks
- USB debugging awareness
- Chart-based data visualization
- Light and dark theme support

## Technologies Used
- Kotlin
- Android Studio
- UsageStatsManager
- UsageEvents
- PackageManager
- AppOpsManager
- MPAndroidChart

## Purpose
The main goal of SpyScan is not to act as an antivirus, but to provide users with understandable security awareness and privacy-related insights based on Android system data.
